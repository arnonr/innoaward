ข้อกำหนดเส้นทาง API (API Reference Specification)

🔐 ระบบยืนยันตัวตน (Authentication API)

Base: /api/auth
POST /api/auth/register Public

ลงทะเบียนผู้ใช้งานใหม่ แฮชรหัสผ่านด้วย Argon2id ผูกกับ EducationLevel และคืน JWT Token

POST /api/auth/login Public

เข้าสู่ระบบด้วยอีเมลและรหัสผ่าน รับ JWT Token พร้อมข้อมูลโปรไฟล์ที่ Join กับระดับการศึกษา

GET /api/auth/me 🔒 Bearer Token

ดึงข้อมูลโปรไฟล์ของผู้ใช้ปัจจุบันพร้อมความสัมพันธ์ทั้งหมด

📝 ระบบยื่นผลงานและตรวจสอบสถานะ (Submissions & Tracking)

Base: /api/submissions
POST /api/submissions User / Public

สร้างหรืออัปเดตผลงาน ผูกกับ Category, EducationLevel, CompetitionYearCategory ปัจจุบัน และบันทึก TeamMember[] อัตโนมัติ

GET /api/submissions/status/:trackingCode Public

ค้นหาสถานะผลงานแบบ Real-time ด้วย Tracking Code พร้อม Join ข้อมูลหมวดหมู่และระดับการศึกษา

GET /api/submissions/my 🔒 Bearer Token

ดึงรายการผลงานทั้งหมดที่ผู้ใช้งานคนนี้เป็นผู้สร้าง

🏆 Master Data และคลังผลงาน (Masters & Hall of Fame)

Base: /api/masters, /api/winners, /api/announcements
GET /api/masters/years/:year/categories

ดึงรายการสาขานวัตกรรมที่เปิดรับสมัครเฉพาะของปีนั้นๆ (จากตาราง CompetitionYearCategory)

GET /api/winners Query: ?year=&category=&level=

ดึงรายชื่อผลงานที่ได้รับรางวัลทั้งหมด (Hall of Fame) ที่ Join ตาราง Category, EducationLevel, CompetitionYear และ TeamMember ครบถ้วน

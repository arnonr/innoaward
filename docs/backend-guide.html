ข้อกำหนดเส้นทาง API (API Reference Specification)

🔐 ระบบยืนยันตัวตน (Authentication API)

Base: /api/auth
POST /api/auth/register Public

ลงทะเบียนผู้ใช้งานใหม่ แฮชรหัสผ่านด้วย Argon2id และคืน JWT Token

Request Payload: 
{
  "email": "user@kmutnb.ac.th",
  "password": "Password123!",
  "fullName": "สมชาย นวัตกรรม",
  "phone": "081-234-5678",
  "institution": "มจพ.",
  "educationLevel": "higher_and_above"
}
Success Response (200): 
{
  "success": true,
  "message": "ลงทะเบียนสำเร็จเข้าสู่ระบบเรียบร้อย",
  "token": "eyJhbGciOiJIUzI1NiIsIn...",
  "user": { "id": "...", "email": "...", "role": "contestant" }
}
POST /api/auth/login Public

เข้าสู่ระบบด้วยอีเมลและรหัสผ่าน รับ JWT Token สำหรับเรียก API อื่น

GET /api/auth/me 🔒 Bearer Token

ดึงข้อมูลโปรไฟล์ของผู้ใช้ที่ล็อกอินอยู่ในปัจจุบัน

📝 ระบบยื่นผลงานและตรวจสอบสถานะ (Submissions & Tracking)

Base: /api/submissions
POST /api/submissions User / Public

GET /api/submissions/status/:trackingCode Public

GET /api/submissions/my 🔒 Bearer Token

ดึงรายการผลงานทั้งหมดที่ผู้ใช้งานคนนี้เป็นผู้สร้าง

PATCH /api/admin/submissions/:id/status 👑 Admin Only

กรรมการหรือแอดมินอัปเดตผลการพิจารณา, Feedback, และมอบรางวัล

🏆 คลังผลงานและประกาศข่าวสาร (Public Data & Hall of Fame)

Base: /api/winners, /api/announcements
GET /api/winners Query: ?year=&category=&level=

ดึงรายชื่อผลงานที่ได้รับรางวัลทั้งหมด (Hall of Fame) พร้อมรองรับตัวกรองปีการประกวด, สาขานวัตกรรม, และระดับการศึกษา

GET /api/news or /api/announcements

ดึงข่าวสารและประกาศผลทางการ พร้อมรายชื่อทีมที่ผ่านเข้ารอบ (Finalists Roster) และผู้ชนะเลิศ

GET /api/config

ดึงข้อมูล 5 สาขานวัตกรรม, เกณฑ์การตัดสิน, เงินรางวัล, และกำหนดการกิจกรรม

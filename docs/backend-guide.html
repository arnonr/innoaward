ข้อกำหนดเส้นทาง API (API Reference Specification)

1. Authentication (`/api/auth`)

POST /api/auth/register

สมัครสมาชิกใหม่ บันทึก Argon2id hash ผูก EducationLevel คืน JWT

POST /api/auth/login

เข้าสู่ระบบด้วยอีเมลและรหัสผ่าน คืน JWT Token + User Profile

GET /api/auth/me

🔒 Bearer Token ดึงข้อมูลโปรไฟล์ผู้ใช้ปัจจุบัน

2. Submissions & Tracking (`/api/submissions`)

POST /api/submissions

สร้าง/แก้ไขผลงาน แนบ coverImage, ลิงก์วิดีโอ/เอกสาร และสมาชิก

GET /api/submissions/status/:code

ตรวจสถานะด้วย Tracking Code (KMUTNB-YYYY-XXXX) พร้อม Joins ครบ

GET /api/submissions/my

🔒 ดึงรายการผลงานทั้งหมดของผู้เข้าแข่งขันที่ล็อกอินอยู่

3. Masters, Winners & Announcements

GET /api/masters/years/:year/categories

ดึงสาขานวัตกรรมที่เปิดรับสมัครเฉพาะของปีนั้นๆ

GET /api/winners

คลังผลงาน Hall of Fame (Filter: ?year=&category=&level=)

GET /api/announcements

ข่าวสาร/ประกาศผลทางการ พร้อมรายชื่อ Finalists/Winners Roster

แผนการพัฒนา 8 ขั้นตอน (Implementation Tasks & Roadmap)

Task 1 Environment & Schema

Prisma Schema & PostgreSQL Migration

ติดตั้ง `@prisma/client`, สร้างฐานข้อมูล `innoaward_dev`, เขียน Schema และรัน `prisma migrate dev`

Task 2 Seed Pipeline

Database Seeding (`prisma/seed.ts`)

นำเข้า Master Years, Categories, EducationLevels, บัญชีผู้ใช้, ผลงานชนะเลิศ 2566–2568, และประกาศผล

Task 3 Core Libs

Core Utilities & Auth Middleware

Prisma Singleton, `Bun.password` Argon2id, ตัวสร้าง Tracking Code และ JWT Role Guard

Task 4 Master Data

Masters & Config Module

Endpoints สำหรับดึงปีการแข่งขัน, 5 สาขาประจำปี, ระดับการศึกษา และกติกาการประกวด

Task 5 Auth Controller

Authentication API Module

ระบบ Register, Login, Me พร้อมการตรวจสอบรหัสผ่านและสร้าง JWT Token

Task 6 Submissions API

Submissions & Status Tracking

ส่งผลงานพร้อมแนบรูปปก `coverImage`, บันทึกสมาชิก, ตรวจสถานะ Tracking และ Admin Review

Task 7 Public Feeds

Winners Hall of Fame & Announcements

คลังเกียรติยศ Hall of Fame และระบบข่าวสารประกาศผลทางการพร้อมรายชื่อผู้เข้ารอบ

Task 8 Integration & E2E

Server Assembly & Full Test Suite

รวมทุกโมดูลใน `src/index.ts`, เปิดใช้งาน Swagger ที่ `/swagger` และรัน `bun test` ทุกชุด

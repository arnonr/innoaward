03

รายละเอียดหน้าจอหลัก (View-by-View Breakdown)

โครงสร้างภายในและองค์ประกอบสำคัญของแต่ละ View

VIEW 1 • #/ Home View

หน้าแรก (Home Landing Page)

  • Hero Section: วิดีโอพื้นหลังไฮเทค, โลโก้ KMUTNB Innovation Awards 2026, หัวข้อธีม "นวัตกรรมขับเคลื่อนเศรษฐกิจและสังคมที่ยั่งยืน"
  • Live Countdown Timer: นาฬิกานับถอยหลังสู่เส้นตายรับสมัคร (15 พ.ย. 2569) แสดงวัน/ชั่วโมง/นาที/วินาที แบบ Real-time
  • 5 Target Domains Grid: การ์ดแสดง 5 สาขานวัตกรรมเป้าหมาย พร้อมไอคอน สีเฉพาะ และแบนเนอร์ภาพ
  • Competition Timeline: ผังไทม์ไลน์บันได 4 ขั้น (เปิดรับสมัคร ➔ ประกาศผล Finalists ➔ วัน Pitching & พิธีมอบรางวัล 26 ม.ค. 2570)
  • Key Awards Highlights: ไฮไลท์ถ้วยพระราชทานฯ และเงินรางวัลรวมกว่า 300,000 บาท
VIEW 2 • #/guidelines Guidelines Hub

คู่มือและเกณฑ์การประกวด (Guidelines Hub)

  • Sticky Subnavigation: แถบเมนูลอยติดด้านบน รองรับ Scroll-spy สลับแท็บอัตโนมัติตามตำแหน่งหน้าจอ
  • Subsections Deep-link: #eligibility (คุณสมบัติผู้เข้าประกวด 2 ระดับ), #domains (ขอบเขต 5 สาขา), #prizes (โครงสร้างรางวัลและเงินรางวัล), #standards (เกณฑ์ TRL และความพร้อมด้านเทคโนโลยี), #criteria (เกณฑ์การให้คะแนน 100 คะแนน)
  • Download Guidelines PDF: ปุ่มดาวน์โหลดประกาศฉบับเต็มของมหาวิทยาลัย
VIEW 3 • #/winners Hall of Fame

ทำเนียบผู้ได้รับรางวัล (Hall of Fame)

  • Multi-Dimensional Filters: กรองผลงานตามปีการศึกษา (2568, 2567, 2566), สาขานวัตกรรม 5 ด้าน, ระดับการศึกษา 2 ระดับ, และช่องค้นหา Keyword
  • Winner Showcase Card: แสดงรูปปกผลงาน, ป้ายระดับรางวัล (Grand Prize, รองชนะเลิศ, ชมเชย), ชื่อผลงาน 2 ภาษา, ชื่อทีม, และสถาบัน
  • Interactive Project Modal: คลิกดูรายละเอียดผลงานฉบับเต็ม, บทคัดย่อ, รายชื่อสมาชิกในทีม, อาจารย์ที่ปรึกษา, และลิงก์วิดีโอ YouTube
VIEW 4 • #/announcements Official Hub

ประกาศผลและข่าวสาร (Announcements Hub)

  • Category Subnav Tabs: ทั้งหมด, ผู้ผ่านเข้ารอบสุดท้าย Finalists, ผลรางวัลชนะเลิศ Winners, และข่าวสารโครงการ
  • Roster Data Table: ตารางแสดงรายชื่อผลงานที่ผ่านการคัดเลือก พร้อมรหัสติดตาม (Code), ชื่อผลงาน, ทีม, และระดับการศึกษา
  • Official PDF Link: ปุ่มดาวน์โหลดเอกสารประกาศทางการพร้อมตราครุฑ
04

ระบบ Modals & มาตรฐาน Accessibility (a11y)

การจัดการหน้าต่างป๊อปอัปและระบบควบคุมการเข้าถึงด้วยคีย์บอร์ด

MODAL 1
Contestant Portal Modal

หน้าต่างสมัครสมาชิก, เข้าสู่ระบบ และฟอร์มยื่นผลงานพร้อมฟิลด์กรอกรูปหน้าปก (coverImage)

State: showPortalModal, portalTab
MODAL 2
Status Tracking Modal

หน้าต่างค้นหาและติดตามสถานะการพิจารณาผลงานจากรหัสติดตาม KMUTNB-XXXX-XXXX

State: showStatusModal, trackingSearch
MODAL 3
Winner Project Modal

หน้าต่างแสดงรายละเอียดโครงงานที่ได้รับรางวัลชนะเลิศ บทคัดย่อ และข้อมูลทีมแบบเจาะลึก

State: selectedWinnerModal
กฎการควบคุม Focus Trapping & Keyboard Accessibility:

1. เมื่อเปิด Modal ใดๆ ระบบจะ Focus ไปยังปุ่มหรือ Input แรกโดยอัตโนมัติ

2. การกดปุ่ม Tab หรือ Shift + Tab จะวนลูปเฉพาะ Element ที่อยู่ใน Modal เท่านั้น

3. การกดปุ่ม Escape จะปิด Modal ทันทีและคืน Focus กลับสู่หน้าจอเดิม

05

กลไก State Management & Live Engines

ระบบประมวลผลแบบ Real-time ภายใน Client

ENGINE 1

URL Hash Router

ดักฟัง Event window.onhashchange เพื่อสลับ State currentView ทันทีโดยไม่ต้อง Reload หน้าเว็บ รองรับ Deep Linking ทุกหมวดหมู่

ENGINE 2

Countdown Engine

คำนวณส่วนต่างเวลากับ Target Deadline ทุก 1,000ms แจ้งเตือนสถานะหมดเขต (timeLeft.expired = true) และปิดปุ่มส่งผลงานอัตโนมัติ

ENGINE 3

Confetti Celebration

เรียกใช้ไลบรารี canvas-confetti เมื่อผู้ใช้ยื่นผลงานสำเร็จ เพื่อสร้าง Micro-reward และประสบการณ์ที่น่าประทับใจ

06

ตารางการเชื่อมต่อกับ Backend API (Elysia.js + PostgreSQL)

แมปปิ้ง Request Payload, Response Format และ Storage

ฟังก์ชันการทำงาน Method Endpoint Payload / Headers Storage & ผลลัพธ์
ดึงทำเนียบรางวัล GET /api/winners None (?year=&category=&level=) บันทึกลง state winners
ดึงข่าวสาร & ประกาศผล GET /api/announcements None (?type=&year=) บันทึกลง state announcementsList
สมัครสมาชิกผู้เข้าแข่งขัน POST /api/auth/register { email, fullName, phone, institution, educationLevel } บันทึก innoaward_token ลง localStorage
เข้าสู่ระบบ POST /api/auth/login { email, password } บันทึก innoaward_token ลง localStorage
ยื่นผลงาน / บันทึกร่าง POST /api/submissions { titleTh, category, educationLevel, coverImage, ... }, Bearer Token ได้รับรหัส KMUTNB-2569-XXXX
ตรวจสอบสถานะผลงาน GET /api/submissions/status/:code Tracking Code ใน URL แสดงผลใน Status Modal
